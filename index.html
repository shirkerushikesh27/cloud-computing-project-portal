Understanding the Project

🎯 Objective

To design and deploy a web application in a Platform as a Service environment.

☁ What is PaaS?

PaaS provides tools and an environment to develop, run and manage applications without managing the underlying servers.

⚙ Deployment Process

Prepare the website, store the source code in GitHub, connect the repository to a cloud hosting platform, and deploy.

Advantages of PaaS

Easy Deployment

Applications can be published online through a hosting dashboard.

Less Infrastructure Work

The cloud provider manages much of the hosting infrastructure.

Online Access

Users can open the deployed application through a web address.
